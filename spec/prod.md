### 2026-08-24 — run `9b85cd`: M2.2 built, and three claims corrected on the way

**M2.2 is Complete, and it is the first Phase-2 milestone this project has been able to mark Complete on the day it was built.** M2.7 and M2.9 both shipped code-complete-but-not-Complete because a gate could not run or a state had never rendered. **Decision: `TriggerOutcome` is `'earned' | 'undetermined'`, not FR-107's word "unearned". This amends FR-107's gloss; it is not a defect.**
*Rationale.* FR-106 is a **disjunction** — limb one *or* limb two. Q27 rules that limb two is never evaluated. Therefore `¬(A ∨ B)` cannot be derived from `¬A` while `B` is unevaluated: the product **cannot** assert a stack has not earned a specialist, only that limb one did not fire and limb two has never run. `i1` reached this independently and queued it; `project-lead` let it stand and referred it to `qa-reviewer`, which confirmed it and sharpened the reasoning — FR-107's **normative** sentence imposes no vocabulary on the non-actionable states, and "unearned" appears only in its trailing gloss.
*Alternatives.* Use "unearned" as written (rejected: it asserts a fact the product has not established, which is the wrong-`done` this project exists to refuse). Build limb two (rejected by Erik at Q27 — it needs schema for a rule nothing has exercised).
*Affects.* FR-107's gloss. The screen says a stack shown as `undetermined` *"is not a stack this product has established did not earn a specialist."*

**Decision: the engagement count on FR-104 derives from `work_session.engagement_id`, not `work_item`.**
*Rationale.* FR-106 conjoins engagements with hours, and FR-105 defines hours as a sum over `work_session.duration_minutes`. A conjunction across two different populations is not a rule anyone can state on a screen — and FR-106 requires the rule to be **stated**. **Decision: `RegisterState` carries three values where FR-108 names two.**
*Rationale.* FR-108 distinguishes *"nothing has been captured"* from *"things were captured and none qualified"*. A third is reachable and is **the state this ledger is actually in**: sessions captured, none naming a stack. Additive — a screen ignoring it still renders.
